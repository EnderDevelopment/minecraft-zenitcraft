# ZenitCraft: Minecraft Texture Pack

ZenitCraft is a comprehensive Minecraft texture pack designed to enhance your gameplay experience. It includes a variety of custom textures, GUI elements, and resource packs tailored for Minecraft version 1.21.11. The pack features a unique design with a focus on polish and detail, providing a visually appealing and immersive environment. It includes custom textures for blocks, items, mobs, and GUI elements, as well as a resource pack for additional visual enhancements.

## Install

1. Download the ZenitCraft texture pack from the GitHub repository.
2. Open Minecraft.
3. Navigate to the "Resource Packs" section in the game settings.
4. Click on "Open Resource Pack Folder."
5. Drag and drop the downloaded ZenitCraft folder into the resource pack folder.
6. Go back to the "Resource Packs" section in the game settings.
7. Enable the ZenitCraft texture pack by selecting it from the list.

## Use

1. Launch Minecraft and select the world where you want to use the ZenitCraft texture pack.
2. The custom textures and GUI elements will automatically apply to your gameplay.
3. Explore the enhanced visuals and enjoy the improved immersion.
